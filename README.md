# Galleria Streets

A third-person, Stick RPG-style browser game set around Galleria Dallas (Alpha Rd, Noel Rd, Montfort Dr, Dallas Pkwy, the Dallas North Tollway and LBJ).

Open `index.html` in a browser to play. It loads three.js r128 from cdnjs and fonts from Google Fonts, so it needs an internet connection.

## Controls

| Key | Action |
| --- | --- |
| WASD / arrows | Walk, drive |
| Mouse (click to lock) | Look |
| Shift (hold) | Skateboard outdoors, sprint indoors |
| Tab | Get in / out of the black SUV |
| Space | Jump, tap again to double jump (handbrake in the SUV) |
| E | Enter / exit doors, free the mouse at Apple product tables |
| M | Bigger map |
| Wheel | Camera distance |

Phones get an on-screen stick and buttons.

## What's in it

- Half-scale street grid with signal-timed traffic, pedestrians, the elevated Tollway and I-635
- Target (enterable) and a McDonald's at Montfort & LBJ
- Two-level Galleria interior: shops, a walk-in Apple store with product tables that link to apple.com, Barnes & Noble with a seated café, a skateable ice rink with a Christmas tree, and a food court with open kitchens and moving escalators
